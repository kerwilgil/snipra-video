# Montage director

Montage is an explicit intent for deliberately sequencing independent events. It may prioritize variety, rhythm, contrast, progression, and energy, while every component remains independently defensible under the Quality Gate.

Record event order, source ranges, transition rationale, and label the result honestly. Transitions must not camouflage incompatible context or broken causality.

## Enhanced Event Pool usage (1.5H+)

When `targeted_evidence.enhanced_event_pool` is present:

- **Diverse order** (`diverse_order_event_ids`): Representatives from each cluster first (by cluster order), then remaining members by rank ASC. This ordering maximizes topical/temporal variety for inspection. Use as a navigation aid, not a selection constraint.
- **Cluster awareness**: Clusters group near-duplicates (1.5G: temporal overlap ≥0.70, or ≥0.50 + same topic OR peak proximity ≤2.0s). Multiple selections from the same cluster are permitted if editorially justified (e.g., different angles, progressive escalation). The Director decides.
- **Refined ranges & anchors**: Each event has `refined_start/end`, `peak_at`, `payoff_window`, `reaction_window` from 1.5D. Use for precise boundary decisions on each component.
- **Topic contexts**: From 1.5E. Check `topic_contexts` to ensure deliberate topical variety or progression.
- **Score/rank as signals**: `overall_score` and `rank` (1.5C) are comparative nomination signals across the pool. They do not mandate inclusion/exclusion.
- **Representative is structural**: `representative_event_id` per cluster is the lowest-rank member. It is not a quality gate.

**Selection rule**: Two or more independent events required. The Director selects based on editorial judgment using all evidence. The enhanced pool's diverse order and cluster structure are tools for discovering variety; they do not constrain the final selection.
