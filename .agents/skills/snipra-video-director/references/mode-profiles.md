# Mode profiles

All modes share `UNDERSTAND → DISCOVER EVENTS → QUALITY GATE → BEST EVENT POOL → OUTPUT INTENT`; profiles change editorial priorities without creating separate pipelines or universal thresholds.

| Profile | Priority evidence |
|---|---|
| Auto | Infer the dominant profile, support mixed content, preserve uncertainty. |
| Gaming | Action, readable resolution/payoff, reaction, skill; avoid menu/loading/idle. |
| Podcast / Interview | Self-contained idea, conflict, turn, memorable line, verbal context. |
| Vlog / Direct to camera | Emotional/narrative change and comprehensible place/action continuity. |
| Tutorial / Educational | Problem, explanation, demonstration, result; keep essential steps. |
| Music / Ambient | Musical structure, energy, visual rhythm, atmosphere; transcript is secondary. |
| Technical / Preserve framing | Accuracy, sequence, diagnosis, proof/resolution; preserve framing when required. |

Do not import Gaming weights or assumptions into another profile without validation.
