# Event understanding

An event is a bounded sequence that may contain `setup → escalation → peak → payoff → reaction`. Not every phase is required, but remaining evidence must make the selected range intelligible. A striking frame is a clue; it is not automatically an event.

Discover candidate events economically, then reason over their temporal relation and audience relevance. Preserve an unsupported outcome as `uncertain`. Event truth remains shared across Hook, Highlight, Montage, Auto, and future Editor IA; only composition changes by intent.
