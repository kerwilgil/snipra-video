# Event coherence

Event coherence asks whether selected source ranges form one comprehensible cause-and-effect chain. Review temporal continuity, source-range count and gaps, scene/context continuity, stable subject/player/speaker identity, transcript/OCR continuity, setup, escalation, peak, payoff, and optional reaction.

Evidence against coherence includes menus, loading, idle, scoreboards without narrative value, large unexplained timeline gaps, subject/context changes, unrelated event joins, missing payoff, and post-payoff dead time. A continuous range is helpful but not sufficient: editorial causality must still be visible.

Rule: a Highlight is one coherent event. Several independent events deliberately joined are a Montage. The P1.1-D review found that current `gaming_highlights` uses distributed slots and multiple source ranges, so it is architecturally a montage-like composition despite its name. Treat that as an implementation finding to review, not a Gaming-only rule or a production change.
