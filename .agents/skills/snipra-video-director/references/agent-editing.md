# Agent editing

The Editor IA is a client of the shared Event Engine and Best Event Pool. It needs: project inspection, a version graph, range preview, deterministic operation API, event/transcript/media panels, operation log, verification signals, undo/redo/restore, and agent chat that returns plans before writes.

P0: inspect, non-destructive versions, split/trim/delete/move, preview, verify, undo/redo/restore. P1: event pool, captions, crop/reframe, audio fades/gain, semantic rough cut. P2: B-roll/overlays/transitions, advanced motion, assisted multi-event montage, preference learning.
