# Editorial core

Editorial value is a defensible relationship across time, not a high-scoring frame. Preserve causality, context, payoff, and semantic integrity; leave material clean when intervention adds no clarity, emotion, or utility.

Auto and Editor IA are clients of the same path: inspect, understand, map events, apply the Quality Gate, form the Best Event Pool, choose an intent, plan, and verify. A mode profile changes priorities, never the core path.

An editorial plan records objective, requested intent, source/version, selected and excluded events, boundary rationale, operations, preview/checkpoint, verification criteria, and unresolved uncertainty.
