# Hook director

A Hook earns attention quickly through surprise, conflict, tension, payoff, reaction, novelty, or curiosity. It is not automatically the shortest clip, the first resolution, the largest audio peak, or the largest model score.

Derive it preferentially from globally strong events in the Best Event Pool, then assess time to interest, time to peak, payoff visibility, reaction, and post-payoff dead time. Start late enough to be immediate but early enough to remain intelligible. A coherent hook from a mediocre event should trigger review against a stronger global event.
