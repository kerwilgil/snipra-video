# Evaluation rubric

Run the lightweight reasoning cases defined in `../evals/evals.json`. A passing response identifies intent, evidence, uncertainty, safety boundary, and correct editorial decision; it must not claim execution.

Evaluate future implementations separately: candidate/event recall, false-positive rate by type, payoff retention, boundary quality, continuity regressions, pool diversity, preview catches, undo/restore integrity, and human acceptance. Do not tune production thresholds merely to satisfy Skill evals.
