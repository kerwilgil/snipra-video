# Verification

After a material change, verify the output range—not only command success—across: visual correctness, audio continuity, timing, narrative continuity, boundaries, payoff visibility, menu/loading contamination, captions/overlays, and version integrity.

Use deterministic checks for range validity, overlaps, missing media, duration, render existence, and operation ancestry. Use preview/inspection for semantic checks. Report pass, fail, uncertain, evidence, and required rework.
